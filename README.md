Count-consistent holders/players trophy forecaster: it forecasts how many GTA VI players earn each of the 55 trophies in week one, as five quantiles per trophy, from the house's recorded Exophase reads — decomposing each rate into holders over players, fitting recency-weighted log-time trends with an empirical-Bayes share-slope prior, and keeping the forecast count-consistent.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
